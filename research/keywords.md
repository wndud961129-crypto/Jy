# 내 키워드 (keywords.md)

관심 있는 키워드를 모아두는 파일입니다.

- 키워드는 사용자가 직접 정했거나, 사용자가 Claude에게 정하도록 맡긴 것만 적습니다.
- Claude가 정한 키워드는 **[Claude 제안]** 으로 표시합니다. 사용자가 확인하면 표시를 지웁니다.
- 새 키워드는 끝에 추가하고, 기존 키워드는 사용자 요청 없이 지우지 않습니다.
