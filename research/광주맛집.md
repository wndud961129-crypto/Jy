## 1. 광주 대표 음식 7미와 대표 가게

**광주 대표 음식 7미** [1]
- 광주시가 2019광주세계수영선수권대회를 계기로 선정했습니다: 주먹밥, 상추튀김, 보리밥, 한정식, 오리탕, 육전, 떡갈비.
- 시민 1,100명 인식도 조사와 전 국민 공모전(3,486명 참여)을 거쳐 선정위원회가 골랐습니다.

**음식별 모여 있는 곳** [1]
- 송정떡갈비: 1950년대부터 이어졌고, 광주송정역 근처에 떡갈비거리가 있어 찾아가기 쉽다는 점이 선정 이유 중 하나였습니다.
- 오리탕: 광주 북구 유동에 오리요리거리가 있습니다.
- 무등산 보리밥: 증심사 계곡 일대와 지산유원지 일대에 보리밥집이 모여 있습니다.

**대표 가게 예시 (광주MBC 방송 소개 가게)** [2]

| 음식 | 가게 | 위치(구) |
|---|---|---|
| 무등산 보리밥 | 팔도강산 | 동구 |
| 육전 | 육전명가 | 서구 |
| 상추튀김 | 현완단겸 상추튀김 양림점 | 남구 (양림동 근처, 백서로) |
| 주먹밥 | 테스팅 노트 | 서구 |
| 오리탕 | 영미오리탕 | 북구 |
| 떡갈비 | 송정떡갈비 1호점 | 광산구 |
| 계절 한정식 | 서석정 | 북구 |

- 방송 소개 가게일 뿐, "가장 맛있는 집"이라는 뜻은 아닙니다.
- 7곳이 **광주 5개 구에 모두 흩어져 있습니다.** 이것이 이동 방법 비교의 출발점입니다.
- 지금도 영업 중인지, 영업시간은 어떤지는 **미확인**입니다.

## 2. 이동 정보

**지하철** [3]
- 광주 도시철도 2호선 1단계(시청~상무역~월드컵경기장~백운광장~남광주역~조선대~광주역)는 **2028년** 개통 예정이고, 2단계는 2035년 예정입니다.
- 그래서 2026년 11월 현재 지하철은 1호선 한 개 노선만 탈 수 있습니다.
- 1호선이 광주송정역과 이어진다는 내용은 나무위키 [6]에서 봤고 공식 자료로는 확인하지 못했습니다 → **일부 미확인** (광주도시철도공사의 1호선 페이지는 "컨텐츠 준비중"이었음)

**무등산 보리밥거리** [4]
- 위치: 동구 지산동. 버스: "지산유원지" 정류장에 1000번, 두암81번이 섭니다.
- 주차: 가게마다 주차장이 있습니다.
- 보리밥에 막걸리를 곁들여 먹는 곳으로 소개되어 있습니다.

**무등산 증심사지구 자차 경로** [5]
- 고속도로에서 동광주IC → 학운IC(증심사 방향)로 들어갑니다.

**블로그에서만 본 내용 (모두 미확인)**
- 광주송정역에서 송정떡갈비거리까지 걸어서 6~7분 → **미확인**
- 영미오리탕은 주차 가능 → **미확인**
- 증심사 방면 버스는 2026년 10월 31일에 노선이 개편되었다 → **미확인**

## 3. 자차 vs 대중교통 비교

> 아래 비교는 1~2번의 확인된 내용을 바탕으로 Claude가 정리했습니다. **[Claude 제안]**

| 비교 항목 | 자차가 있는 사람 | 대중교통 이용자 |
|---|---|---|
| 흩어진 맛집 7곳(5개 구) | 한 번에 여러 구를 돌기 쉬움 | 지하철이 1개 노선뿐이라 [3] 버스 환승이 많아짐 |
| 무등산 보리밥거리 | 가게마다 주차장이 있어 편함 [4] | 버스 1000번·두암81번으로 갈 수 있음 [4] |
| 송정떡갈비 | 차로 갈 수 있음 (주차는 **미확인**) | 기차로 광주송정역에 오면 바로 근처라 유리함 [1] |
| 막걸리 같은 술 | 운전 때문에 마실 수 없음 | 부담 없이 마실 수 있음 |
| 주차 | 가게·지역마다 다름. 확인 필요 | 주차 걱정 없음 |
| 2호선 개통 전(2028년 전) | 영향 없음 | 도심 이동 불편이 남아 있음 [3] |

**한 줄 정리**: 자차는 **흩어진 맛집을 많이 도는 데** 유리하고, 대중교통은 **송정역 도착과 술 곁들인 식사**에 유리합니다.

## 4. 해결방안

> **[Claude 제안]** 실제 이동 시간은 확인하지 않았습니다. 계획을 세울 때는 지도 앱으로 다시 확인해야 합니다.

**대중교통 이용자: "권역으로 묶어 하루 2~3곳만"**
1. 맛집을 지역별로 묶습니다.
   - 송정권(광산구): 떡갈비 — 기차로 도착한 직후나 떠나기 직전에 들르기
   - 도심권(남구·동구): 상추튀김(양림동 근처) — 양림동 조사 노트와 함께 둘러보기
   - 무등산권(동구 지산동): 보리밥 — 버스 1000번·두암81번 이용 [4]
   - 북구권: 오리탕
2. 하루에 2~3개 권역만 고릅니다. 다 돌려고 하면 환승이 너무 많아집니다.
3. 2호선 1단계가 개통되면(2028년 예정 [3]) 다시 조사합니다.

**자차가 있는 사람: "주차 먼저, 술은 마지막"**
1. 출발 전에 가게 주차장이나 근처 공영주차장을 먼저 확인합니다.
2. 도심에서는 한 번 주차한 뒤 걸어서 둘러봅니다.
3. 막걸리를 곁들이는 보리밥집 같은 곳은 동승자가 운전하거나 대리운전을 미리 정해 둡니다.
4. 먼 곳(송정·무등산)을 차로 가고, 가까운 곳끼리는 묶어서 갑니다.

**두 경우 모두**
- 방문 전에 영업시간과 휴무일을 확인합니다. (지금 영업 여부는 **미확인**)
